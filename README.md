# MK컴퓨터 홈페이지

## 실행
index.html을 Chrome 또는 Edge에서 열면 바로 실행됩니다. 설치나 빌드가 필요하지 않습니다. 인터넷이 없어도 기본 글꼴로 표시되며 주요 기능은 동작합니다.

## 수정
- config.js: 실제 주소, 전화번호, 영업시간 및 추천 PC 구성 변경
- index.html: 문구와 섹션 구조 변경
- styles.css: 최상단 색상 변수 및 화면 크기별 디자인 변경
- app.js: 모바일 메뉴, 상품 필터, 상담 창 동작

추천 PC는 실제 판매 상품이 아닌 구성 예시입니다. 가격과 재고는 표시하지 않습니다. 매장 정보의 빈 문자열을 실제 정보로 바꿔 주세요. 하단의 사업자 정보와 지도 영역은 index.html에서 별도로 수정해야 합니다. 지도는 실제 지도 API가 아닌 위치 등록 전 안내 화면입니다.

상담 창은 FormSubmit(https://formsubmit.co/)을 통해 c72unix@gmail.com으로 이름, 답변 이메일, 선택 전화번호, 서비스, 문의 내용을 POST 전송합니다. 최초 문의 접수 시 수신 메일함의 활성화 링크를 눌러야 합니다. 보안 확인은 유지됩니다. 실제 운영은 HTTP/HTTPS 웹 호스팅에서 진행하세요. 로컬 파일(file://)에서는 이메일 전송이 지원되지 않을 수 있습니다. 수신 이메일을 변경하려면 index.html의 form action과 안내 문구를 수정하세요. 활성화 및 실제 수신 확인은 매장 소유자가 수행해야 합니다.

외부 의존성: Google Fonts의 Noto Sans KR 웹폰트(연결 실패 시 시스템 글꼴 사용). 모든 PC 이미지는 파일 안에 포함된 SVG 일러스트입니다.


## Supabase 문의 저장
공개 연결 정보는 config.js에 있습니다. Supabase SQL Editor에서 supabase-permissions.sql을 실행해야 저장됩니다. 방문자는 지정된 필드의 신규 접수만 가능하며 기존 문의를 읽거나 변경할 수 없습니다. 접수 내역은 소유자의 Supabase Table Editor → inquiries에서 확인하세요.

흐름: 입력 검증 → Supabase 저장 → FormSubmit 이메일 전송 화면. 이메일 전송/활성화가 완료되지 않아도 저장에 성공한 문의는 DB에 남습니다. 두 서비스의 작업은 하나의 트랜잭션이 아닙니다. 네트워크 오류 발생 시 중복 제출 전에 Table Editor에서 접수 여부를 확인하세요.

공개 접수 API는 로그인 없이 쓰기가 가능하며 서버에서 검증하는 CAPTCHA/요청 제한은 아직 없습니다. FormSubmit의 CAPTCHA는 이메일 전송 단계에만 적용됩니다. 실제 공개 운영 전 접수 API의 스팸 방지를 추가해야 합니다.
